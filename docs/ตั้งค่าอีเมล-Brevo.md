# ตั้งค่าอีเมล (ลืมรหัสผ่าน / ยืนยันอีเมล) ด้วย Brevo ฟรี

Render ฟรีบล็อกพอร์ต SMTP (25/465/587) จึงใช้ Gmail SMTP ไม่ได้ ระบบนี้ส่งผ่าน Brevo ทาง HTTPS แทน (ฟรี 300 ฉบับ/วัน ไม่ต้องใช้บัตร ไม่ต้องมีโดเมน)

1. สมัครที่ https://www.brevo.com (ใช้อีเมลของร้าน)
2. เมนู Senders, domains & dedicated IPs → Senders → Add a sender → ใส่อีเมลที่จะใช้ส่ง (เช่น Gmail ของร้าน) แล้วกรอกรหัสยืนยันที่ส่งไปอีเมลนั้น
3. เมนู SMTP & API → แท็บ API keys → Generate a new API key แล้วคัดลอก (ขึ้นต้น xkeysib-)
4. ที่ Render → บริการ → Environment ตั้งค่า (วางคีย์ตรงนี้เท่านั้น อย่าส่งในแชท):
   - `MAIL_MODE` = `brevo`
   - `BREVO_API_KEY` = คีย์จากข้อ 3
   - `MAIL_FROM` = `ร้านอักษรไหว <อีเมลผู้ส่งที่ยืนยันในข้อ 2>`
5. กด Save → Render จะรีสตาร์ตเอง แล้วลองกด "ลืมรหัสผ่าน" (ดูในโฟลเดอร์สแปมด้วย)
