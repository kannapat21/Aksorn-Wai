# ย้ายร้านอักษรไหวขึ้นโฮสต์ฟรี (Netlify) ทีละขั้น

ทุกบริการในคู่มือนี้ **สมัครฟรีและไม่ต้องใช้บัตรเครดิต** สมัครด้วยบัญชี GitHub ได้ทุกเจ้า ใช้เวลาราว 30–45 นาที

| ส่วนของร้าน | ใช้บริการ | ฟรีได้เท่าไร |
|---|---|---|
| ตัวเว็บ + หลังบ้าน | Netlify | 300 เครดิต/เดือน (ถ้าหมด เว็บหยุดชั่วคราวจนต้นเดือนใหม่ ไม่มีการเก็บเงิน) |
| ฐานข้อมูล (บัญชี ออเดอร์) | Turso | 5GB |
| ไฟล์สินค้า + ฟอนต์ลูกค้า | Supabase Storage | เก็บ 1GB · โหลดออก 5GB/เดือน · ไฟล์ละไม่เกิน 50MB |
| ถอดเสียงไทยทำซับ | Groq | มีโควตาฟรีต่อชั่วโมง/วัน (ดูที่ console.groq.com → Limits) |
| เรนเดอร์วิดีโอ + เบิร์นซับ | เบราว์เซอร์ของลูกค้าเอง | ไม่ใช้แรมเซิร์ฟเวอร์เลย |

> ทำไมไม่ใช้ Vercel: แพ็กฟรีของ Vercel (Hobby) เขียนในข้อตกลงว่าใช้ได้เฉพาะงานส่วนตัว ไม่ใช่เพื่อการค้า ร้านขายของจึงเสี่ยงโดนปิด Netlify ฟรีไม่มีข้อห้ามนี้

---

## ขั้นที่ 1 · เตรียมค่าลับ 2 ตัว (ทำในเครื่องตัวเอง)

เปิด Terminal ในโฟลเดอร์ร้าน แล้วรันคำสั่งนี้ **2 ครั้ง** จดผลไว้ (ห้ามใช้ค่าเดียวกัน)

```
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

- ครั้งแรก = `DOWNLOAD_LINK_SECRET`
- ครั้งที่สอง = `PAYMENT_WEBHOOK_SECRET`

ตั้งรหัสแอดมินใหม่ยาวอย่างน้อย 12 ตัว จดไว้เป็น `ADMIN_PASSWORD`

## ขั้นที่ 2 · ฐานข้อมูล Turso

1. เข้า https://turso.tech → **Sign up** → เลือก **Continue with GitHub**
2. กด **Create Database** ตั้งชื่อ เช่น `aksornwai`
   - Region เลือก **AWS US East (Ohio)** หรือที่ใกล้ที่สุดในฝั่งสหรัฐตะวันออก (ให้อยู่ใกล้เซิร์ฟเวอร์ Netlify เว็บจะเร็วกว่า)
3. เข้าไปในฐานข้อมูลนั้น จด **URL** ที่ขึ้นต้นด้วย `libsql://` ไว้เป็น `DATABASE_URL`
4. กด **Create Token** (สิทธิ์ Read & Write, ไม่หมดอายุ) คัดลอกไว้เป็น `DATABASE_AUTH_TOKEN`

ตารางทั้งหมดร้านจะสร้างให้เองตอนเปิดครั้งแรก ไม่ต้องทำอะไรเพิ่ม

## ขั้นที่ 3 · ที่เก็บไฟล์ Supabase

1. เข้า https://supabase.com → **Start your project** → **Continue with GitHub**
2. กด **New project** ตั้งชื่อ `aksornwai` · ตั้งรหัสฐานข้อมูลอะไรก็ได้ (ไม่ได้ใช้) · Region เลือก **Southeast Asia (Singapore)** ลูกค้าไทยจะโหลดไฟล์เร็ว
3. เมนูซ้าย **Storage** → **New bucket**
   - ชื่อ `shop-files`
   - **Public bucket: ปิด** (สำคัญมาก ถ้าเปิด ใครก็โหลดของพรีเมียมได้ฟรี)
   - Restrict file size: 50 MB
4. เมนูซ้าย **Project Settings → API Keys** (หรือ **Data API**)
   - จด **Project URL** (`https://xxxx.supabase.co`) เป็น `SUPABASE_URL`
   - คัดลอก **secret key** (`sb_secret_...`) หรือ **service_role** ในแท็บ Legacy ก็ได้ เป็น `SUPABASE_SERVICE_KEY`
   - คีย์นี้เปิดไฟล์ได้ทุกไฟล์ **ห้ามส่งให้ใครหรือวางในแชต**

> Supabase ฟรีจะ **พักโปรเจกต์ถ้าไม่มีใครใช้ 7 วัน** ถ้าโดนพัก เข้าหน้า Supabase แล้วกด Restore ได้ฟรี (ร้านที่มีลูกค้าเข้าทุกวันจะไม่โดน)

## ขั้นที่ 4 · อัปไฟล์สินค้าขึ้น Supabase (ทำครั้งเดียว ในเครื่องตัวเอง)

ในโฟลเดอร์ร้าน (เปิด Terminal ที่โฟลเดอร์นั้น) วางทีละบรรทัด แทนค่าของตัวเอง

```
git pull
npm install
SUPABASE_URL=https://xxxx.supabase.co SUPABASE_SERVICE_KEY=วางคีย์ npm run upload:supabase
```

- อัปทั้งหมดราว 450MB (90 ไฟล์) ขึ้นกับความเร็วเน็ต
- ไฟล์ที่ใหญ่เกิน 48MB (ตอนนี้มีไฟล์เดียว คือ ProRes แนวนอนของ "ป้ายไฟนีออน") จะถูกบีบเป็น `.zip` ให้อัตโนมัติ ลูกค้าจะได้ไฟล์ zip แทน
- ถ้าเน็ตหลุดกลางทาง รันคำสั่งเดิมซ้ำได้ ไฟล์ที่อัปแล้วจะถูกข้าม
- ถ้าวันหลังเรนเดอร์สินค้าใหม่หรือแก้ไฟล์เดิม รันใหม่โดยเติม `-- --force` ท้ายคำสั่ง

## ขั้นที่ 5 · คีย์ถอดเสียง Groq

1. เข้า https://console.groq.com → สมัครด้วย GitHub หรืออีเมล
2. เมนู **API Keys** → **Create API Key** คัดลอกไว้เป็น `GROQ_API_KEY` (ขึ้นต้นด้วย `gsk_`)

## ขั้นที่ 6 · อีเมลจริงด้วย Gmail (ใช้ส่งอีเมลยืนยัน/ลืมรหัสผ่าน)

1. ใช้ Gmail ของร้าน เปิด **การยืนยันแบบ 2 ขั้นตอน** ที่ https://myaccount.google.com/security
2. เข้า https://myaccount.google.com/apppasswords สร้าง App password ชื่อ `aksornwai` จะได้รหัส 16 ตัว เป็น `SMTP_PASS`

## ขั้นที่ 7 · เปิดเว็บบน Netlify

1. เข้า https://app.netlify.com → **Sign up with GitHub**
2. **Add new project → Import an existing project → GitHub** → เลือกรีโพ `Aksorn-Wai`
3. Branch to deploy: เลือก branch ที่รวมงานนี้แล้ว (ปกติคือ `main` หลังกดรวม PR) ค่าอื่นปล่อยไว้ ไฟล์ `netlify.toml` ตั้งไว้ให้แล้ว
4. ก่อนกด Deploy (หรือหลังก็ได้ที่ **Project configuration → Environment variables**) กด **Add a variable** ใส่ตามตารางนี้

| ชื่อ | ค่า |
|---|---|
| `NODE_ENV` | `production` |
| `BASE_URL` | `https://ชื่อเว็บ.netlify.app` (ดูชื่อจริงหลัง deploy ครั้งแรก แล้วกลับมาแก้) |
| `SHOP_NAME` | `อักษรไหว` |
| `ADMIN_EMAIL` | อีเมลแอดมินของคุณ |
| `ADMIN_PASSWORD` | รหัสจากขั้นที่ 1 |
| `DOWNLOAD_LINK_SECRET` | ค่าสุ่มตัวแรก |
| `PAYMENT_WEBHOOK_SECRET` | ค่าสุ่มตัวที่สอง |
| `DATABASE_URL` | `libsql://...` จาก Turso |
| `DATABASE_AUTH_TOKEN` | token จาก Turso |
| `SUPABASE_URL` | Project URL |
| `SUPABASE_SERVICE_KEY` | secret key จาก Supabase |
| `GROQ_API_KEY` | `gsk_...` |
| `PAYMENT_PROVIDER` | `manual` (ลูกค้าโอนแล้วกดยืนยัน คุณอนุมัติที่ /admin/transfers) |
| `PROMPTPAY_ID` | เบอร์พร้อมเพย์ 10 หลัก |
| `PROMPTPAY_NAME` | ชื่อบัญชีพร้อมเพย์ |
| `MAIL_FROM` | `อักษรไหว <อีเมลgmailของร้าน>` |
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `587` |
| `SMTP_USER` | อีเมล Gmail ของร้าน |
| `SMTP_PASS` | App password 16 ตัว |
| `LEGAL_NAME` | ชื่อร้าน/ชื่อเจ้าของ ที่จะแสดงในหน้านโยบาย |
| `CONTACT_EMAIL` | อีเมลติดต่อร้าน |

ไม่ต้องใส่ `DATABASE_FILE`, `MAIL_MODE`, `RENDER_MODE` (บน Netlify เป็นโหมดเบราว์เซอร์ให้อัตโนมัติ)

5. กด **Deploy** รอราว 2–3 นาที
6. ได้ชื่อเว็บแล้ว กลับไปแก้ `BASE_URL` ให้ตรง แล้ว **Deploys → Trigger deploy** อีกครั้ง
7. ลองเข้าเว็บ ล็อกอินด้วยอีเมล/รหัสแอดมิน ลองสั่งของฟรี ลองปรับแต่ง และลองทำซับคลิปสั้น ๆ

ถ้าเปิดเว็บแล้วเจอข้อความภาษาไทยบอกว่าตั้งค่าไม่ครบ ให้ดูชื่อตัวแปรในข้อความแล้วเติมใน Environment variables จากนั้น Trigger deploy ใหม่

## สิ่งที่ต่างจากตอนรันในเครื่อง (บอกตรง ๆ)

- **เครื่องลูกค้าเป็นคนเรนเดอร์** ทั้งแอนิเมชันที่ปรับแต่งและคลิปซับ ใช้ Chrome/Edge/Safari รุ่นใหม่ ครั้งแรกเบราว์เซอร์จะโหลดตัวเข้ารหัสวิดีโอราว 32MB (ครั้งต่อไปไม่ต้องโหลดอีก)
- ทดสอบใน Chrome จริงแล้ว: MP4 แนวตั้ง 3 วินาทีใช้ราว 28 วินาที (รวมโหลดตัวเข้ารหัสครั้งแรก) · ProRes 4444 แนวนอน 5 วินาทีใช้ราว 48 วินาที ไฟล์ 106MB · เบิร์นซับคลิป 16 วินาทีใช้ราว 14 วินาที
- **ProRes ยาว ๆ กินแรมเบราว์เซอร์มาก** (ราว 100MB ต่อ 5 วินาที) มือถือรุ่นเก่าอาจเรนเดอร์ไม่ไหว ควรทำบนคอมพิวเตอร์ ส่วน MP4/WebM เบามาก
- **คลิปของลูกค้าไม่ถูกอัปขึ้นเว็บ** ร้านรับแค่เสียงที่ตัดเป็นช่วงสั้น ๆ ไปถอดความที่ Groq แล้วเบิร์นซับในเครื่องลูกค้า ดีต่อความเป็นส่วนตัว แต่ถ้าลูกค้าเปิดจากเครื่องอื่น ต้องเลือกไฟล์คลิปเดิมอีกครั้ง
- ไฟล์ฟอนต์ที่ลูกค้าอัปได้สูงสุด 4MB ต่อไฟล์ (ขีดจำกัดของ Netlify)
- **โหลดออกจาก Supabase ได้ 5GB/เดือน** ถ้าลูกค้าโหลด ProRes เยอะ (ไฟล์ละ 15–50MB) จะหมดเร็ว ไฟล์ MP4/PNG เล็กมากไม่น่าห่วง ดูยอดใช้ได้ที่หน้า Supabase → Usage
- ตัวกันสแปม (จำกัดคำขอต่อนาที) นับแยกต่อเครื่องของ Netlify จึงหลวมกว่าตอนรันเครื่องเดียว
- ระบบซับแบบเดิมที่ถอดเสียงในเครื่อง Mac ยังใช้ได้เหมือนเดิมถ้ารันในเครื่องตัวเอง

## ถ้า Netlify ใช้ไม่ได้ (เช่น ขึ้นว่าบัญชีถูกระงับ) · ทางสำรอง Render

ขั้นที่ 1–6 (Turso, Supabase, Groq, Gmail) ใช้ของเดิมทั้งหมด เปลี่ยนแค่ขั้นที่ 7

1. เข้า https://render.com → **Get Started** → สมัครด้วย GitHub
2. **New → Blueprint** → เลือกรีโพ `Aksorn-Wai` (ไฟล์ `render.yaml` ตั้งไว้ให้แล้ว เลือกเซิร์ฟเวอร์สิงคโปร์และแพ็กฟรี)
3. Render จะถามค่าที่ต้องกรอกเอง ใส่ตามตารางขั้นที่ 7 (ค่าสุ่มสองตัวกับ SMTP_HOST/PORT Render ใส่ให้แล้ว)
4. ได้ชื่อเว็บ `https://aksornwai-xxxx.onrender.com` แล้ว กลับไปใส่ `BASE_URL` ให้ตรง แล้วกด **Manual Deploy**

ข้อจำกัดของ Render ฟรี
- ถ้าไม่มีคนเข้า 15 นาที เว็บจะหลับ คนแรกที่เข้ามาต้องรอราว 1 นาทีให้เว็บตื่น
- ให้ใช้ 750 ชั่วโมงต่อเดือน (พอเปิดทั้งเดือน) และมีโควตาเน็ตขาออกต่อเดือน แต่ไฟล์สินค้าโหลดตรงจาก Supabase จึงไม่กินโควตานี้
- Render เขียนไว้ว่าแพ็กฟรี "ไม่แนะนำสำหรับใช้งานจริง" และบางบัญชีอาจถูกขอยืนยันบัตรตอนสมัคร
