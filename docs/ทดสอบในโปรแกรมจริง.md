# Checklist ทดสอบไฟล์ในโปรแกรมตัดต่อจริง

ไฟล์อยู่ที่ `storage/products/order-now/` (หรือซื้อผ่านเว็บในโหมดทดสอบแล้วโหลดจากหน้าดาวน์โหลด)
เตรียมคลิปพื้นหลังที่มีสีสัน 1 คลิป (ควรมีส่วนที่เป็นสีเขียวหรือสีสว่างด้วย จะเห็นปัญหาขอบชัดขึ้น)

ทุกโปรแกรมให้เช็ก 5 ข้อนี้เหมือนกัน:

- [ ] **ข้อความไทยครบ**: "สั่งซื้อเลย" เห็นไม้หันอากาศ ไม้เอก บน ส, สระอี ไม้โท บน ซ ครบ ไม่ซ้อนกัน ไม่ลอยผิดที่
- [ ] **ลบพื้นหลังหมด**: ไม่เหลือกรอบสี่เหลี่ยมสีเขียว/ดำ
- [ ] **ขอบสะอาด**: ซูม 200% ดูขอบตัวอักษร ไม่มีเส้นสีเขียวหรือขอบดำเกินมา (ขอบดำหนาของตัวอักษรเป็นดีไซน์ ไม่ใช่ปัญหา)
- [ ] **ท่าเคลื่อนไหว**: เด้งเข้า (ขยายเกินแล้วหดกลับ) ค้างไว้ แล้วจางออกจนหายสนิทตอนจบ ยาว 3 วินาที
- [ ] **ขนาดถูก**: ไฟล์แนวตั้งเต็มจอโปรเจกต์ 9:16 ไฟล์แนวนอนเต็มจอ 16:9 ไม่ยืด ไม่บีบ

## CapCut มือถือ (iOS / Android)

ไฟล์: `order-now_mp4_green_1080x1920.mp4`, `order-now_mp4_black_1080x1920.mp4`

- [ ] ส่งไฟล์เข้ามือถือ (AirDrop / LINE Keep / Google Drive) แล้วบันทึกลงคลังภาพได้
- [ ] โปรเจกต์ใหม่ 9:16 ใส่คลิปพื้นหลัง → "ซ้อนภาพ" → "เพิ่มซ้อนภาพ" → เลือก MP4 พื้นเขียว
- [ ] แตะคลิป → "ลบพื้นหลัง" → "Chroma key" → ดูดสีเขียว → ความเข้ม (Intensity) ประมาณ 20-40
- [ ] เช็ก 5 ข้อด้านบน (ขอบ: ถ้ามีเขียวติด ลองเพิ่ม "เงา"/Shadow)
- [ ] ลองไฟล์พื้นดำ: ซ้อนภาพ → แตะคลิป → "ผสม" (Blend) → "Screen" → พื้นดำหาย
      หมายเหตุ: โหมด Screen จะทำให้ขอบดำของตัวอักษรหายไปด้วย และตัวอักษรจะโปร่งขึ้นบนพื้นสว่าง (เป็นธรรมชาติของ Screen)
- [ ] Export 1080p แล้วเปิดดูคลิปที่ได้ในแอปรูปภาพ

## CapCut คอม (Windows / Mac)

ไฟล์: MP4 พื้นเขียว / พื้นดำ ทั้งแนวตั้งและแนวนอน

- [ ] Import → ลากไฟล์พื้นเขียวไปแทร็กบนคลิปหลัก
- [ ] แผงขวา Video → Remove BG → Chroma key → ดูดสีเขียว ปรับ Intensity / Shadow
- [ ] เช็ก 5 ข้อ
- [ ] ลองไฟล์พื้นดำ ตั้ง Blend = Screen
- [ ] ลองทั้งโปรเจกต์ 16:9 (ไฟล์แนวนอน) และ 9:16 (ไฟล์แนวตั้ง)

## Premiere Pro

ไฟล์: `order-now_prores4444_*.mov` (หลัก), MP4 พื้นเขียว (สำรอง)

- [ ] Import ไฟล์ MOV → วางบน V2 เหนือคลิปหลัก → พื้นโปร่งใสทันทีโดยไม่ต้องใส่เอฟเฟกต์
- [ ] ถ้าพื้นเป็นสีดำ: คลิกขวาไฟล์ใน Project → Modify → Interpret Footage → Alpha Channel ไม่ติ๊ก "Ignore Alpha Channel"
- [ ] เช็ก 5 ข้อ (ขอบ: ไม่ควรมีขอบดำบางๆ หรือขอบเทารอบตัวอักษรเกินจากขอบดีไซน์)
- [ ] สำรอง: MP4 พื้นเขียว + Ultra Key ดูดสีเขียว
- [ ] Export H.264 แล้วเปิดดู

## DaVinci Resolve

ไฟล์: ProRes 4444 (หลัก), MP4 พื้นเขียว (สำรอง)

- [ ] ลาก MOV เข้า Media Pool → วางบน Video 2 → พื้นโปร่งใสทันที
- [ ] ถ้าพื้นเป็นสีดำ: คลิกขวาคลิปใน Media Pool → Clip Attributes → Alpha Mode = Straight
- [ ] เช็ก 5 ข้อ
- [ ] สำรอง: MP4 พื้นเขียว + 3D Keyer
- [ ] Deliver แล้วเปิดดู

## Final Cut Pro (Mac)

ไฟล์: ProRes 4444 (หลัก), MP4 พื้นเขียว (สำรอง)

- [ ] Import MOV → วางเป็น Connected Clip เหนือคลิปหลัก → พื้นโปร่งใสทันที
- [ ] เช็ก 5 ข้อ
- [ ] สำรอง: MP4 พื้นเขียว + Effects → Keying → Keyer
- [ ] Share → Export File แล้วเปิดดู

## อื่นๆ (เลือกได้ตามที่มี)

- [ ] เปิดไฟล์ `order-now_webm_alpha_*.webm` ใน Chrome: ลากไฟล์ใส่หน้าต่าง Chrome จะเห็นพื้นโปร่งใส (ลายตารางหรือพื้นเว็บ)
- [ ] OBS: เพิ่ม Media Source เป็นไฟล์ WebM → พื้นโปร่งใส

## ทดสอบเว็บร้านบนมือถือจริง

- [ ] รัน `npm start` แล้วเปิดจากมือถือในวง Wi-Fi เดียวกัน (`http://<IP เครื่อง>:3000`)
- [ ] หน้าสินค้า: คลิปพรีวิวเล่นเอง มีลายน้ำ สลับแนวตั้ง/แนวนอนได้
- [ ] สมัครสมาชิก → หน้าสินค้า กด "ซื้อเลย" → หน้าชำระเงินโหมดทดสอบ → กด "จำลองจ่ายสำเร็จ"
- [ ] ได้หน้า "ชำระเงินสำเร็จ" และเห็นอีเมลยืนยันพิมพ์ในหน้าจอ terminal
- [ ] เปิดคลัง เลือก "CapCut มือถือ" → เห็นชุด 3 ส่วนพื้นเขียว + PNG และ MP4 เขียว/ดำ พร้อมคู่มือ CapCut
- [ ] เลือก Premiere → เห็นไฟล์ ProRes · ออกจากระบบแล้วเข้าใหม่ คลังยังอยู่ครบ
- [ ] โหลดไฟล์บนมือถือได้ และบันทึกลงเครื่องได้ (iPhone: กดค้างที่วิดีโอ → บันทึกวิดีโอ หรือ Files)
- [ ] `/admin` เข้าด้วยผู้ใช้ `admin` + รหัสใน `.env` → เห็นคำสั่งซื้อ สถิติโปรแกรม และจำนวนสมาชิก
